Embed demo

A stand-in for a host site such as ca.org. Everything outside the map below is this page's own markup and CSS.

Host-page canary — this must stay bold, orange and stacked (not a flex row), and this box must keep its dashed border. If either changes, the embed's styles escaped their container.

A host <button> for comparison:

1. Default embed

Just the two lines an embedder has to copy. Defaults to 600px tall. 

<div id="ca-area-map"></div>
<script src="https://cawscit.github.io/area-maps/embed.js"></script>

2. Custom height, no header, meetings preloaded

Options are read from data-* attributes on the container (or on the <script> tag, to set a default for every map on the page). 

<div
  id="ca-area-map-compact"
  data-height="420px"
  data-header="false"
  data-meetings="auto"
></div>

3. Mounted from JavaScript

The bundle also exposes window.CAAreaMap for pages that build their markup dynamically. 

CAAreaMap.render('#ca-area-map-manual', { height: '320px', header: false });

Loaded last so the auto-mount for #ca-area-map has already run, proving both paths coexist.
